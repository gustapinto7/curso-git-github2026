Um curso para iniciantes aprenderem a trabalhar com versionamento de código e repositórios remotos com GitHub

Confira tudo o que temos no nosso youtube. é grátis.





\## Fluxo de trabalho git local



1 - git checktou -b nova branch

2 - cria ou atualiza arquivos

3 - git status

4 - git add .

5 - git status

6 - git commit -m "minha mensagem"

7 - git checkout main

8 - git merge nova branch





\## Fluxo de trabalho GITHUB <> local (projeto próprio ou da sua empresa)



1 - git clone <endereço do projeto>

2 - git checkout -b nova branch

3 - cria atualiza os arquivos

4 - git status

5 - git add <arquivos>

6 - git commit -m "minha mensagem"

7 - git push origin <nova branch>

8 - abrir pull requests no GitHub para main

9 - excluir nova branch origin

10 - git checkout main

11 - git branch -D <nome da branch>





\# Fluxo de trabalho GITHUB <> local open source 



1 - fork do projeto para seu próprio github

1 - git clone <endereço do projeto>

2 - git checkout -b nova branch

3 - cria atualiza os arquivos

4 - git status

5 - git add <arquivos>

6 - git commit -m "minha mensagem"

7 - git push origin <nova branch>

8 - abrir pull requests no GitHub da branch fork para a main do projeto original

9 - excluir nova branch origin

10 - git checkout main

11 - git branch -D <nome da branch>
